## Product iteration (feedback → shipped, with commits)

The full traceability table — each user request, the feature that shipped, and
its commit — is in **[docs/GROWTH.md](GROWTH.md)**. Summary of what shipped:

- **Invoice history** page with search + status/role filters
- **Invoice preview** before sending
- **PDF export** for any invoice (and paid receipts)
- **Onboarding walkthrough** (first-run tour + navbar "?")
- **Payment reminders** (one-click copy-to-send)
- **Dark/light mode** toggle (dark default)
- **UX polish**: retry on all load errors, stronger buttons, better empty states
- **Analytics**: activity-page CSV export + live usage stats
